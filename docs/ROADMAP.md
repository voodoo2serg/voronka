# Следующие задачи

Рабочий цикл Telegram с медиабанком, редактором шагов, опросом, PDF, задачами и паузой реализован. Развитие не должно задерживать запуск этого цикла.

1. Нативные загрузки MAX/VK, публикации в их публичные площадки, проверенные генераторы ссылок. Пока медиа этих платформ отправляется резервной HTTPS ссылкой.
2. Групповые ключевые слова с cooldown и журналом переходов в личку; редакционный календарь и согласование публикаций.
3. Поиск, теги, исполнители/сроки задач, CSV, более подробная аналитика по воронкам и источникам.
4. Вебинарные шаблоны с календарными датами, напоминания ожидающим ответа участникам, уведомления в тех-чат.
5. Роли на отдельную площадку внутри подключения; библиотека продуктов, платежи и подтверждённое слияние контактов.
6. Несколько worker с сериализацией по identity, глобальные лимиты платформ, нагрузочные/аварийные проверки и внешние метрики.
7. Видеоплеер с измеряемым прогрессом и самостоятельный веб-курс. Нажатие «Продолжить» не доказывает просмотр.

WhatsApp — отдельный официальный адаптер с учётом бизнес-аккаунта, окна сообщений и шаблонов.
